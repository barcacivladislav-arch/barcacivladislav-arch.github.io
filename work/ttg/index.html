Brand guidelines

How to use the identity.

The guidelines turn the concept into rules for everyday production. Each example below comes from the TTG brand book.

Logo and clear space

Use the full height of the mark around the horizontal lockup. Use one quarter of the mark for the stacked logo and standalone symbol. For the wordmark alone, use the height of the O.

See the primary mark and incorrect uses

Palette and contrast

Green, navy, and ivory form the core palette. Orange is an accent. Use light type on dark fields and dark type on light fields. Keep orange and green apart.

Typography

Libertinus Serif sets the headlines and large figures. Rethink Sans carries body copy, labels, and calls to action.

The ribbon pattern

Run it edge to edge, crop into its curves, contain it in a shape, or let it enter from one side. Give it its own space away from photography.
